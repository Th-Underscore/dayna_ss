text-generation-webui Extension · System Architecture · v0.2

DAYNA Story Summarizer

A schema-driven structured story-state engine for long-form roleplay. After every exchange a per-subject agent updates a persistent world model — characters, groups, elements, events, arcs — then retrieval, rendering, and director instructions feed it back into the next prompt. The entire update logic lives in an editable JSON schema, not in code.
