## 10. Methodology

- **Turn wall time:** difference between consecutive `--- turn N/150 ---` timestamps (last turn uses last log timestamp).
- **Local call time:** `total=Xs` field from `local-call` lines. Includes non-GPU overhead (queue, network, post-processing).
- **Cloud call time:** duration from `guide: cloud user turn in Xs`, `replan: cloud response in Xs`, `judge: verdict in Xs`, `auditor: N verdicts in Xs`.
- **DSS vs Writer:** `?/generate` = DSS (no phase_id), `reply/generate` = Writer.
- **LLM/wall ratio:** sum of all call durations / total wall time. Exceeds 100% because `total=` includes overhead and calls may overlap with non-LLM work.
- **Parsing:** Python stdlib regex, single-pass over 163,597,928-byte log (951,964 lines).
